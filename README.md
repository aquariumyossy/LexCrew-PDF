# LexCrew-PDF

カードへ PDF を置き、印付きの A4 をこの PC のダウンロードフォルダの「証拠」へ書く Windows デスクトップアプリです。事件データベースは持ちません。生成先のフォルダは選べません。

仕様の正本は [引継ぎ.md](引継ぎ.md) です。

## 必要なもの

- Windows
- Python 3.11 以上
- [WebView2 ランタイム](https://developer.microsoft.com/microsoft-edge/webview2/)（システムの Edge WebView2）
- 游明朝 `C:\Windows\Fonts\yumin.ttf`

游明朝が無いときは PDF を書かず、前回のファイルも消しません。

## 起動と停止

このフォルダで、次のどちらかを使います。

| 操作 | ファイル |
|------|----------|
| 起動 | `起動.bat` をダブルクリック |
| 停止 | `停止.bat` をダブルクリック |

`起動.bat` は、同じ仮想環境で既に動いているときはもう1つ開きません。`停止.bat` が止めるのは、このフォルダの `.venv` で動いている `lexcrew_pdf` だけです。

コマンドから起動する場合は次です。

```powershell
cd C:\LexCrew-PDF
.\.venv\Scripts\python.exe -m lexcrew_pdf
```

起動ログの最初の行は `cards-ready` です。この行より前に PDF は開きません。カードを描いたあと、ファイルがあるカードだけ先頭ページのサムネイルを作ります。

## 初回の準備

`.venv` がまだ無いときは、このフォルダで次を実行します。

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

`-e` を付けると、`python -m lexcrew_pdf` が `src` のコードを直接読みます。

## 画面でできること

1. 起動すると、ダウンロードフォルダの「証拠」に保存済みのカードがあればそれを出す。無ければ甲第１号証から甲第６号証までの空のカードが6枚出る。
2. カードの末尾にある「カードを追加」で、次の番号を足す。「削除」でそのカードを消すと、後ろの証拠番号が詰まる。枝番を消したときは、残った枝番の番号も詰まる。ヘッダーの欄では「甲第N号証」「乙第N号証」「丙第N号証」「疎甲第N号証」「疎乙第N号証」「疎丙第N号証」「別紙N」「資料N」を選べる。N は証拠番号で、`資料N` ならカードは資料１、資料２…、ファイル名は `資料001：` になる。疎甲第N号証の枝番は `疎甲001-1：` になる。カード右下のつまみで順番を変えると、証拠番号、印、ファイル名が付いて変わる。枝番を番号の外へ動かすと枝番なしになる。枝番なしのカードは枝番に入らない。
3. 「ファイルを追加」は、まだ PDF の無いカードの中央にだけ出る。ファイルがあるカードは「差替」と「右に90°」で扱う。サムネイルへ別の PDF をドロップしても差替になる。
4. 「枝番」で、の１、の２がそれぞれ別のカードになる。ページの入っていない枝番は PDF を出さない。
5. サムネイルは、そのカードの出すページの先頭で、右肩に証拠番号の赤印が付く。クリックすると編集ウィンドウが開く。左に出すページが縦に並び、ドラッグで順番を変え、右肩の X でそのページを外す。右はその並びをスクロールして見る。最後の1枚は外せない。「元に戻す」で、その枝番のページ順を原本に戻す。編集中の証拠番号は、メインのカードで差替・回転・削除などができない。枝番なら、その枝番の番号が付く。
6. 「証拠PDFを生成」でダウンロードフォルダの「証拠」に印付き PDF を書く。生成中はボタンを押せない。画面の右上に保存先のパスが出る。

カードを変えるたびに、ダウンロードフォルダの `証拠\layout.json` を上書きします。アプリのフォルダには案件データを書きません。

## アーキテクチャ

Python と画面は1つのプロセスです。ページは pywebview の `js_api` で Python を直接呼びます。HTTP サーバは立てず、Chromium も同梱しません。描画はシステムの WebView2 です。

```text
起動.bat
  └─ python -m lexcrew_pdf
       ├─ ダウンロードフォルダの layout.json を読む。PDF は開かない
       └─ pywebview + WebView2
            ui/index.html
            ui/app.js              カード、ドロップ、編集ウィンドウを開く
            ui/edit.html           ページの並べ替え、除外、元に戻す
                 │
                 ▼
            window.Api             画面からの呼び出し
                 │
                 ▼
            Session                カードの状態。保存先はダウンロードフォルダ
                 │
     ┌───────────┼────────────┬─────────────┐
     ▼           ▼            ▼             ▼
  layout.py   pages.py     plan.py       names.py
  配置JSON    ページ順     生成ジョブ    ファイル名と印
                 │
                 ▼
              stamp.py             A4、赤印、回転、A3分割、JPEG
                 │
                 ▼
              write.py             証拠フォルダへ書き、前回分だけ消す
```

| モジュール | 役割 |
|------------|------|
| `src/lexcrew_pdf/__main__.py` | `python -m lexcrew_pdf` の入口 |
| `window.py` | 窓と、エクスプローラからのドロップ |
| `session.py` | 画面が使う操作。起動時の表示は配置だけで、PDF を開かない |
| `layout.py` | カード、スロット、ページ順、`layout.json` |
| `names.py` | 甲乙丙丁戊、印の文字、出力ファイル名 |
| `pages.py` | 除外、本体、枝番グループ。本体が空の指定は原本順に戻す |
| `plan.py` | カードから、印字へ渡すジョブを作る |
| `stamp.py` | 原本を A4 縦へ載せ、出力の1ページ目だけ赤印を押す |
| `write.py` | `名前.pdf.writing` に書いてから置き換える |
| `ui/` | カード画面とページ編集。ビルド工程は無い |

PDF の読み書きは PyMuPDF です。印のフォントは游明朝を埋め込みます。

## 保存されるもの

この PC のダウンロードフォルダの「証拠」にだけ書きます。ダウンロードフォルダを別の場所へ移していても、Windows が示しているその場所を使います。

- `layout.json` はカード、書名、回転、A4分割、ファイルの場所、ページ順、前回書いたファイル名です。回転 0、分割オフ、原本順のページは省略します。フォルダの中の PDF は相対パス、外の PDF は絶対パスです。
- 出力 PDF の名前は `甲001：書名.pdf` です。枝番があるときは `甲001-1：書名.pdf` です。区切りは全角コロンです。印は `甲第１号証`、枝番の印は `甲第１号証の１` です。疎甲第N号証は `疎甲001：書名.pdf`、枝番は `疎甲001-1：書名.pdf` です。別紙N は `別紙001：`、資料N は `資料001：` です。カードの欄には、このファイル名を出します。
- 書名が空のときは、そのカードの最初の PDF の拡張子を除いた名前を使います。
- 消すのは、前回このアプリが書いた名前のうち、今回残さないものだけです。`メモ.pdf` のように自分で置いたファイルは残します。原本 PDF はコピーしません。
