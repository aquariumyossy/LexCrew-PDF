LexCrew-PDF

1. LexCrew-PDF-Setup-1.5.0.exe を実行します。管理者権限は不要です。今サインインしているユーザーにだけ入ります。
2. 署名の無いセットアップを初めて実行すると、Windows が「PC が保護されました」と表示することがあります。そのときは「詳細情報」を押し、「実行」を押します。
3. インストール先は %LOCALAPPDATA%\Programs\LexCrew-PDF です。
4. スタートメニューに「LexCrew PDF」が入ります。
5. 完了画面の「デスクトップにショートカットを作る」と「今すぐ起動」は、最初からオンです。外すと、その操作はしません。
6. 次回からは、スタートメニューか、デスクトップのアイコンから起動します。閉じると終了します。常駐や、ログイン時の自動起動はありません。

更新するときは、新しいセットアップを実行します。起動中の LexCrew PDF は終了します。以前のフォルダで動いているものも終了します。他の Python は止めません。以前のフォルダ自体は消しません。デスクトップの「LexCrew-PDF」は、リンク先が以前の runtime\pythonw.exe で、引数が -m lexcrew_pdf のときだけ消します。ダウンロードフォルダの「LexCrew-PDF-Downloads」にある証拠PDFと、layout.json などの配置は残ります。

アンインストールは、Windows の「設定」の「アプリ」から「LexCrew PDF」を選びます。アンインストールの前に、起動中のアプリは止まります。消すのは、このアプリが入れたファイルです。「LexCrew-PDF-Downloads」と、以前のフォルダは消えません。

必要なもの。

- Windows 64bit
- Microsoft Edge WebView2 ランタイム
- 游明朝（yumin.ttf）。初期の印に使います
- ゴシックの印を使うときは游ゴシック（YuGothM.ttc）

証拠 PDF とカードの配置は、この PC のダウンロードフォルダの「LexCrew-PDF-Downloads」に保存されます。生成が終わると、そのフォルダが開きます。アプリのフォルダとは別です。

番号の形は、甲第N号証のような N のある形のほか、「別紙」や「参考資料」のように N の無い形も使えます。N が無いときは、印も見出しもその文字になり、ファイル名は書名だけです。枝番を足しても「の１」は付きません。ページをまとめることはできます。

ヘッダーの「スタンプ」で、印を付けるかを選べます。初期状態では付けます。外すと、出力、サムネイル、編集画面に印は出ません。マスキング、トリム、傾き、分割、白黒、頁番号、枝番のまとめはそのままです。ファイル名は書名だけになり、同じ書名は「書名 (2).pdf」のように分けます。以前の配置でこの設定が無いときは、印を付けたままです。

証拠PDFを生成するとき、置き換えるファイル、消すファイル、残して別名にするファイルがあるときは、書く前に確認します。自分で置いた同じ名前の PDF は残し、新しいファイルは「書名 (2).pdf」や「甲001 書名 (2).pdf」になります。前回このアプリが書いた同じ名前は、その場で置き換えます。
